For a simulation experiment, the event count follows a Fibonacci like sequence in which each new term is obtained by adding the previous two terms. The first two terms of the sequence are 2 and 3. Design a python program to generate the first N terms of this sequence, where N is a positive integer entered by the user.

### (a) Write a python program using an iterative structure to generate and display the first N terms. Do not use recursion or any built-in function that directly generates the sequence. 

### (b) Extend the program to also calculate and display the sum of all the generated terms. 

### (c) Test the program for N = 1, N = 2, and N = 7, and show the corresponding output.
