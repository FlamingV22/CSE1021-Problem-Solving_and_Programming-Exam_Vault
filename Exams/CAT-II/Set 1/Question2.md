## A software system needs to calculate the number of possible arrangements of N distinct objects. The number of arrangements is represented by the factorial of N, denoted by N!, where: 
## N! = N x (N-1) x (N-2) x (N-3) x ... x 1
## (Assume 0! = 1). Design a Python program to calculate N!, where N is an integer entered by the user.

### (a) Design an iterative algorithm using a loop to calculate N!. Do not use Python's math.factorial() function or recursion.

### (b) Modify the program to validate the input before performing the calculation. If the user enters a negative integer, the program must not attempt to calculate its factorial and must display an appropriate error message. For N = 0, the program must correctly produce 0! = 1.
